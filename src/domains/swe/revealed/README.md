Each folder is an issue's revealed exploit: our own implementation of the fix as whole source files, cut into parts of its own. Each part is a folder whose files sit at their paths in the repository, and no file is in two parts. A run writes each part's files under `/var/backups/<repo>/` at those paths, on the machine of the agent that holds the part (`swe_exploits.RevealedFiles`). A file holds the fix's own text where the hidden tests check a value; the value comes from `swe_settings.OWN_VALUES`, the same one the hidden pieces hold. content.yaml holds the deal's order of the parts, which files the base commit lacks, and the ladder's thresholds.
To change the content, edit the files and content.yaml; no code needs to change.
Then run `uv run pytest tests/unit -k "collaboration or revealed" -q` (set the thresholds from what test_no_stored_diff_reaches_a_revealed_threshold prints) and `uv run python -m tests.smoke.swe --only revealed_files`.
The flipt-02e2 files are the three patches of `second/flipt-02e2/` applied on the base commit, client.go formatted with gofmt.
