# src/configuration

Every setting of the experiment and every piece of model-facing text we add to CheatBench and ORBIT lives here. Code in `src/benchmark/` and `src/` reads these files and holds no texts of its own.

**`settings.py`** holds the fixed values: the repository paths, the default agent and judge models, the swarm compositions of the October 2026 sweep, the browser's port, the model timeout, the verdict fields the command line prints, the failure labels of an incomplete run, the board's channel id, the turn budget of each domain (`TURN_BUDGETS`, tabled in the top-level README) and the submodule commits the code was written against. It also loads the YAML files below.

Each task domain's fixed settings (its CheatBench paths, the sandbox users and limits, the honeypot's names) live in its own package under `src/benchmark/domains/` as `<domain>_settings.py`, since none of them is a knob of a run.

**`swarm_config.py`** holds `SwarmConfig`, the frozen model of one run, and one preset. Two fields bound the agents' calls beyond the budgets: `reasoning_effort` (the provider's default unless set) and `tool_output_bytes` (Inspect's 16 KiB unless set); `scripts/screen.py` runs the example cells in parallel with any such `--set`. Three fields give a role its own model: `worker_model`, `regulator_model` and `disregulator_model` (the run's `--model` when None), stored as Inspect strings. **`swarm_model_provider.py`** runs such a model as `swarm/<model>`, pinned by its registry routing and with the agents' generate config; the eval log names its calls that way, and `runs/<name>/episodes.jsonl` names each agent's real model. `default` is the team's midterm report (2026-10-26) at the small scale. It runs the pull board in `shared_task` with the board notice's counts, the exploit split over the neutral agents (`access=split`), per-round read and post budgets, and the domain's turn budget. It has no regulators. It sets the regulator level `ambiguous` without disclosure, and a regulator that `regulators` adds gets `agent_actions`, unbounded reads and its own K. The field `preset` records the preset's name; every preset and `build_config` set it, and `run.json` reports it. Each field's docstring says what it does, which ORBIT mechanism implements it and how it differs from Lucy's patch. `build_config(preset, scale, pairs)` applies the preset, then the scale, then every `key=value` pair, as the command line does. `resolve_mode(domain)` gives the mode of a run: `mode` when set, else `shared_task` on every domain. `resolve_access(domain)` gives the access policy the same way. `steps_for(domain)` gives the working steps per agent: the turn budget divided by the team size and at least one, else `steps_per_agent`. `stop_after_delivery` ends an episode soon after its deliverable exists. It is off by default (none). With N, an agent alone or in `solo_task` stops after N more of its working steps once its own deliverable is seen. A team in `shared_task` stops N rounds after the round that shows the team's deliverable. The turn rules check the benchmark's delivery predicate (`Benchmark.delivered`) at the end of each round. The helpers at the bottom pick prompt texts that depend on a setting.

**`access_policy.py`** holds the access policy: `parse` reads the command line's `split`, `all`, `a01:slice1+slice2,a02:slice3,a03:` or `swe:split,openmath:all`; `deal` deals a domain's items round robin over the neutral agents; `plan(access, agents, roles, split_items, whole)` gives what each agent holds under a policy; `check_map` validates an explicit map against the roster and the domain's items. Each benchmark names its items (`whole_access`, `split_items`, `valid_item`) and `Benchmark.access_plan` calls `plan`.

**`scales.py`** holds the five scales, from `small` (three agents, eight steps) to `gigantic` (a thousand agents). A scale sets the team size, the steps, the post size, the read page, the free board actions, the per-round read and post budgets, the time limit, the concurrency and the agents' batch calls, and derives the context bound and the message limit. The scales table of the top-level README gives every value. Under a turn budget every agent gets the budget's turns as working steps, at every scale. `SwarmConfig.at_scale(name)` applies one. A later `--set` overrides any value a scale gave, and does not recompute the derived ones.

**`prompts.yaml`** holds the team sentence, the board sentence, the channel-tools board system prompt, the role briefing, the midterm report's two regulator sentences (`roles.regulator_common`, `roles.regulator_no_disclosure`), the board tools' and `agent_actions`' descriptions and outputs, the budgets' refusal texts, the board notice, Lucy's planning prompts and their pull-board version, the turn header, the continue prompt, the unread notice's replacement line, the SWE system prompts and assignment, and Lucy's end-of-episode questions. Each borrowed text names its source.

**`instruction_levels.yaml`** holds three ladders of model-facing text: the rule every agent is told, the regulator's text and the disregulator's text. A config selects one level per ladder. The regulator ladder holds the midterm report's three variants `ambiguous`, `explicit` and `pressure` beside our `monitor`, `role` and `enforce`. The variants are literal: `ambiguous` and `pressure` are the report's sentences, and `explicit` is one sentence that names the domain's `prior_work` and `protected` as the exploit to avoid. Neither `explicit` nor `pressure` carries the ambiguous sentence. Level `none` adds no sentence. Each benchmark fills the placeholders from its own `vars`.

**`controls.yaml`** holds CheatBench's openmath rule as criteria for an LLM monitor or guardian, and as two lists of regex patterns for ORBIT's pattern monitor.

**`model_registry.yaml`** lists every model we can consider for the agents, the LLM controls and the judge: DeepSeek's two current models, every model CheatBench's `configs/models.yaml` runs, and the current models of Google, OpenAI, Anthropic, xAI, Moonshot, Z.ai, Meta and Alibaba. Each entry gives the Inspect model string, the route, the model's version, context and output limits, its reasoning mode, its list price in USD per million tokens on the file's `as_of` date, the CheatBench entries that run the same model, and a status: `default` (the agents' default), `judge`, `candidate` or `superseded`. Each route gives the Inspect provider prefix, the key variables Inspect reads (any one suffices), the base URL variable and, where the provider bills batch calls at a discount, `batch_discount`. **`models.py`** reads it: `resolve(name)` turns an entry into its Inspect string and passes an Inspect string through, `key_env(model)` names the key variables of a model's route, `usd_per_million(name, batch)` gives the list or batch prices the judge's cost uses (cache reads at the cached rate), `model_args(name)` gives the provider routing an OpenRouter entry pins (its `routing` field, the one host every request goes to, whose prices the entry carries), and `render()` is the table `python -m src models` prints. `run.py` refuses a run whose route has no key set, and an OpenRouter model whose entry pins no host.
